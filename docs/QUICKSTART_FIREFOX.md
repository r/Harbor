# Firefox Setup Guide

Firefox is Harbor's primary browser. Follow **[the canonical Quickstart](../QUICKSTART.md)** from the beginning for prerequisites, builds, bridge installation, both add-ons, model configuration and demos.

- [Load both Firefox extensions](../QUICKSTART.md#set-up-firefox-recommended).
- [Add and test a configured default model](../QUICKSTART.md#configure-a-model).
- [Prepare tools and Agentic Tool Use](../QUICKSTART.md#check-tools-and-agentic-tool-use).
- [Troubleshoot setup](../QUICKSTART.md#troubleshooting).

Temporary add-ons disappear when Firefox restarts. Load both again through `about:debugging#/runtime/this-firefox`. After rebuilding during development, use **Reload** there and refresh the demo page.
