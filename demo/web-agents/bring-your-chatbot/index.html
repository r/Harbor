Bring Your Own Chatbot (BYOC) Demo

This page writes no chat UI of its own. It calls agent.chat.open() and the Web Agent API's implementer — Harbor, in this browser — opens a chat surface that runs on your own model. Click "Chat with Acme Shop" below to try it.

📋 How BYOC Works

1
The page calls agent.chat.open()

Clicking the chat button runs window.agent.chat.open({ systemPrompt, style }) — a system prompt describing the assistant, and style hints like an accent color and which side of the screen to open on. The page can also advertise tools with <link rel="mcp-server">, as this page's <head> does.

2
Harbor asks whether the site may open a chat

The first call to chat.open() from this origin prompts you for the chat:open permission. Deny it and the call rejects; this page catches that and shows an inline message instead of pretending it worked.

3
Harbor's chat opens and runs on your own model

Harbor draws the chat panel on this page. Because the page could reach that panel, Harbor treats every message in it as this site's prompt. Your first message prompts Harbor to ask, once, whether this site may send prompts to your model — that's the model:prompt permission. If you've picked your own agent in Harbor, it answers and can use what it knows about you; otherwise Harbor's built-in model does. Replies use this page's visible text (the product grid below), not the MCP tools this page advertises — Harbor's chat doesn't call those yet.

4
This site wrote no chat UI

Every bubble, input box and typing indicator you see belongs to Harbor, not to Acme Shop. A different implementer of the same API — for example a native app hosting this page — could show its own chat surface instead, using the same agent.chat.open() call.

⚠️

Web Agent API Required

This demo requires an implementer of agent.chat.open() — Harbor, for example. Install one to try the "Bring Your Own Chatbot" feature!
