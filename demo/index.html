Web Agent API · working examples

Try your AI on the web.

A page can ask to use your AI. Your agent can call the page’s tools. Explore both directions with Harbor, your chosen model, and permissions you control.

Start the walkthrough →

Before you begin

  1. Follow the Quickstart to build Harbor and its native bridge.
  2. Load the single Harbor extension from extension/dist-firefox/ in Firefox.
  3. Check that the bridge is connected and your model is ready. Then open a demo and review its permission request.

Harbor supplies window.ai, window.agent, and document.modelContext. You choose the model and connected MCP servers.

How pages offer tools

Harbor implements document.modelContext from the W3C WebMCP proposal. Pages register JavaScript tools that agents can call. The Web Agent API also lets pages ask to use the person’s chosen AI.

Build your own example

Give your coding assistant the starter guide for the API, examples, and capabilities. Add it to your project and start building a page that works with the visitor’s AI.
